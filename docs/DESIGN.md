# jiantieban 界面规则

面板用 AppKit，设置和首启用 SwiftUI。原则：像系统组件一样安静，键盘优先，颜色和字体只用系统语义值，自动适配深浅色。数值以代码为准（`PanelMetrics`、`ClipCellView`、`Motion`），这里只记规则。

## 1. 面板

- **窗口**：非激活 `NSPanel`，不抢目标 App 焦点；出现在鼠标所在屏幕、距顶 15%；跟随当前 Space，全屏 App 上也能弹出；失焦后按设置延迟（默认 0.35s）关闭。
- **材质**：`NSGlassEffectView`，浅色模式补一层 25% 白 tint（对齐 Spotlight 的亮度），深色不加；“兼容”风格改用 `NSVisualEffectView` `.popover`。玻璃装进按圆角裁剪的容器，避免角上出硬边。
- **尺寸**：宽 640（设置 520–760，下次启动生效）；高度随内容，最多 560；圆角 28；顶栏 64；区块之间靠留白分隔，不画分隔线。
- **行**：固定行高 56，标题起点 x = 80，与搜索文字对齐；密钥视图的组标题 28 高，只出现在每组第一行上方。
- **选中**：圆角填充，深色白 12%、浅色 label 色 10%；不用系统蓝。
- **字体**：搜索 18、标题 15、时间等 meta 12、右侧信息等宽 12、展开正文等宽 12、来源 / 组标题 11。
- **行上不放按钮**：动作全走键盘和右键菜单；按住 ⌘ 0.3 秒显示快捷键提示和 ⌘1–9 角标，松开即消失。
- **筛选**：顶栏 chip 为 全部 / 文本 / 图片 / 收藏 / 密钥；只有非“全部”时才显示当前筛选标签。
- **展开**：选中停留后按设置行数自动展开；⌘R 展开全文，密钥显示明文和引用，图片显示预览；换行即收起。
- **提示**：一次性结果用 toast（如“已存为密钥 · ⌘Z 撤销”“已复制，请按 ⌘V 粘贴”）；持续状态放顶栏下的一行（vault 未同步）或顶栏按钮（启用一键贴回）。
- **不用模态弹窗**：面板失焦即关，危险操作用“再按一次确认”。
- **输入法**：面板出现切到 ABC，关闭恢复原输入法。

## 2. 键盘

- 面板键位只用 ⌘；⌃ 留给用户自己的键盘映射层，导航键忽略 ⌃⌥⇧。
- ↩、Esc、↑↓ 固定；其余动作可在设置里录制、解绑、恢复默认。
- 保留组合：⌘A / C / V / X（搜索框编辑）、⌘Q / H / W / M（系统）、⌘1–9（快速贴回）。
- 任意可打印字符直接进入搜索框；搜索框为空时 ←/→ 切换筛选。
- 默认键位见设置 → 快捷键，或 `Core/Keymap.swift`。

## 3. 动效

- 高频操作不加动画：移动、打字、切筛选、按住 ⌘ 出提示、面板出现 / 收起。
- 一次性变化给短动画：行展开 0.15s，toast 进 0.12s / 出 0.2s，删除 / 撤销行淡入淡出。
- 动画不挡按键：动画中再按键直接跳到新状态。
- 系统“减少动态效果”打开时全部为 0。

## 4. 首启

两页，SwiftUI：

1. 欢迎页：“你的剪贴板，终于有了记忆”，说明后台记录、热键调出、搜索、贴回；按钮“开始使用”。
2. 权限页：标题“启用一键贴回”，解释辅助功能权限只用于模拟 ⌘V。主按钮“启用一键贴回”（请求过后变为“重新打开系统设置”），次按钮“先用仅复制模式”。已授权时只剩“完成”。

关窗或选择仅复制模式都算完成首启，之后不再弹。没有权限时 App 完整可用，只是贴回需要用户自己按 ⌘V。

## 5. 菜单栏

菜单项依次为：显示面板、贴回状态行（“一键贴回已启用”或“仅复制模式 · 启用一键贴回…”，后者点击请求权限）、设置…、清空历史（二次确认）、退出 jiantieban。

## 6. 设置

SwiftUI 窗口，七页：

| 页 | 内容 |
|---|---|
| 通用 | 唤醒热键（⇧⌘V / ⇧⌘C / ⌥⌘V 预设或录制）、登录时启动、失焦关闭延迟、选中停下后展开行数 |
| 快捷键 | 面板动作的键位录制 / 解绑 / 恢复默认 |
| 历史 | 保留时长（24 小时 / 7 天 / 30 天 / 永久）、最多保留条数、单条截断长度、收藏永久保留；说明贴回过的记录始终保留 |
| 贴回 | 纯文本（固定开启）、图片贴为图片或文件 |
| 隐私 | 隐私模式、自动排除疑似密钥、记录浏览器页面来源 |
| 外观 | 视觉风格（自动 / Liquid Glass / 兼容）、面板宽度 |
| 高级 | 默认编辑器、OCR 语言、在访达中显示数据目录、清空历史、版本号 |

规则：改动即时保存到 `UserDefaults`；需要重启才生效的项在控件旁写明；不放未实现的选项；固定行为用禁用的开关加说明。
