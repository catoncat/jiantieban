# jiantieban 发布前人工验收清单

需要真人操作的项。每次发布前在 macOS 26+ 上用 `make app` 的 release 构建跑一遍。

## 0. 构建

- [ ] `make test` 全部通过
- [ ] `make app` 产出并签名 `build/jiantieban.app`，启动后菜单栏出现图标

## 1. 面板

### 热键与显示
- [ ] 默认 ⌘⇧V 唤出 / 隐藏面板（先停用占用同键的工具）
- [ ] 设置页切到 ⇧⌘C / ⌥⌘V 或录制新组合后立即生效
- [ ] 面板出现在鼠标所在屏幕、距顶部 15%；全屏 App 下也能弹出
- [ ] 失焦后按设置的延迟关闭
- [ ] 打开面板输入法切到 ABC，关闭后恢复
- [ ] 深色 / 浅色下玻璃效果正常；外观选“兼容”后下次启动换成 vibrancy
- [ ] 面板宽度（520–760）下次启动生效

### 键盘
- [ ] ↑↓ 移动，⌘↑ / ⌘↓ 跳首尾，Esc 关闭，⌘, 打开设置
- [ ] 任意可打印字符聚焦搜索框
- [ ] 搜索框为空时 ←/→ 切换 全部 / 文本 / 图片 / 收藏 / 密钥
- [ ] ⌘S 收藏（时间前出现 ★）；⌘D 删除，⌘Z 撤销
- [ ] ⌘O：文本用设置里的编辑器（留空用系统默认）打开，图片用默认 App 打开
- [ ] ⌘R 展开 / 收起；选中停留后按设置的行数自动展开
- [ ] 按住 ⌘ 约 0.3 秒显示快捷键提示和视口前 9 行的 ⌘1–9 角标；⌘1–9 贴回对应行；滚动后角标跟随视口第一行
- [ ] 设置 → 快捷键：录制新组合、解绑、恢复默认；下次打开面板生效；⌘A/C/V/X 等保留键不能被占用

### 搜索
- [ ] 关键词搜索（含中文、1–2 个字的短词）
- [ ] `:img` / `:i`、`:text` / `:t`、`:fav` / `:f` 只看对应类型
- [ ] `:secret` / `:s` 进密钥视图（见 §2）
- [ ] 图片里的文字（OCR）能搜到

### 贴回
- [ ] 已授权辅助功能：↩ 把文本贴进目标 App；菜单栏显示“一键贴回已启用”
- [ ] 未授权：↩ 写入剪贴板、关闭面板并提示“已复制，请按 ⌘V 粘贴”；面板顶栏有“启用一键贴回”按钮；菜单栏显示“仅复制模式 · 启用一键贴回…”
- [ ] 授权状态改变后无需重启即切换模式
- [ ] 图片贴回为图片；设置“图片贴回方式 = 文件”后贴入文件引用
- [ ] 贴回过的记录超过保留时长后仍在；只复制的记录照常过期

### 浏览器来源
- [ ] 在 Chrome、Helium 普通窗口复制后，展开该行显示页面标题和 URL；⌥⌘O 回到原页面
- [ ] Chrome 首次使用弹系统“自动化”授权
- [ ] 无痕窗口复制不记来源；设置里关闭后不再记录

## 2. 密钥（需要已安装 jt）

### 标记与撤销
- [ ] 文本行 ⌘L（或右键“标记为密钥”）：提示“已存为密钥 · ⌘Z 撤销”，随即进入命名
- [ ] 标记 OpenAI key：命名框预填 `<最近用过的命名空间>/OPENAI_API_KEY` 并整体选中；认不出的类型只预填 `<命名空间>/`，光标在末尾；Esc 保留默认名，显示“未命名密钥”
- [ ] 命名框外 ⌘Z：记录恢复明文，收藏 / 时间保留，`jt ls` 里刚建的那条没了
- [ ] 命名框里 ⌘Z 是文字撤销；关面板 / 切筛选 / 改搜索词 / 再标记或删除一条后，⌘Z 不再撤销那次标记
- [ ] 引用记录上 ⌘L 无反应，右键没有“取消密钥”
- [ ] CLI `jiantieban mark-secret <id> [name]` 等效
- [ ] 数据库里引用记录的 `content` 只有 `jt://secret/<id>`，没有真值

### 粘贴语义
- [ ] 普通记录：↩ 贴原文；⌘↩ 标记为密钥并贴引用（关闭面板，没有撤销）
- [ ] 引用记录：↩、⌘↩、⌘1–9 贴引用；⌘⇧↩ 贴明文；⌘R 展开显示明文和引用
- [ ] 右键“粘贴密钥引用” / “粘贴明文”正常
- [ ] 时间线里删除引用记录只删本地，可 ⌘Z，`jt ls` 不变

### 密钥视图
- [ ] 列出 `jt ls` 的全部记录（包括终端 `jt add` 的），条数一致；本地标记过的只出现一次
- [ ] 按命名空间分组，组标题只在每组第一行上方；没有 `/` 的在最后“未分组”；组内按名称排
- [ ] 行标题只显示 `/` 后半段，默认名显示“未命名密钥”；右侧是遮罩
- [ ] 搜索只匹配名称，空格隔开的词都要出现，不分大小写
- [ ] ⌘E 改名后 `jt ls` 里名字变了；改到别的命名空间，行挪到新组并保持选中；给“未命名密钥”改名同样预填 `<命名空间>/…`
- [ ] ⌘D 先提示再按一次，第二次才从 jt 删除；移开选中后要重新确认；没有 ⌘Z
- [ ] 收藏 / 打开 / 回到页面在 jt 记录上不出现（右键、⌘ 提示都没有）
- [ ] `JT_BIN` 指到不存在的路径后进密钥视图：空态写出读不到 jt 的原因
- [ ] vault 有没提交或没推送的改动时显示“有未同步的改动 · 在终端运行 jt sync”；终端 `jt sync` 后重进视图提示消失；改名 / 删除后提示随即出现且面板不卡；vault 不是 git 仓库时从不显示
- [ ] App 里任何操作都不触发 `jt sync`

### 引用记录跟随 jt
- [ ] 终端 `jt mv <引用> ns/NAME` 后打开面板：引用记录随后显示新名，按新名能搜到
- [ ] 终端 `jt rm` 一条后打开面板：引用记录显示“密钥已删除”；↩ / ⌘R / 改名提示已从 jt 删除，⌘D 能删掉这条记录
- [ ] 在密钥视图改名 / 删除后回到时间线，对应引用记录同步变化
- [ ] 打开面板、搜索、切 `:text` / `:img` / `:fav` 时不启动 jt 进程（Activity Monitor 看不到 jt）

### CLI / Skill
- [ ] `jiantieban help` 与实际命令一致；`secrets` / `annotate` / `resolve` / `unmark-secret` 打印去向并以退出码 2 退出
- [ ] `jt resolve <引用> --exec sh -c 'test -n "$JT_SECRET" && echo ok'` 输出 ok，不输出真值；加 `--env NAME` 时注入的是 NAME
- [ ] 按 `skills/jiantieban-secret/SKILL.md` 让 Agent 走一遍消费流程

### 没有 jt
- [ ] 卸下 jt（或 `JT_BIN` 指向不存在的路径）后，剪贴板采集、搜索、贴回照常

## 3. 首启、菜单栏与设置

- [ ] 全新用户（`defaults delete rs.jiantieban firstRunDone`）首次启动出现欢迎页，“开始使用”进入“启用一键贴回”页
- [ ] “启用一键贴回”打开系统授权，之后按钮变为“重新打开系统设置”；授权后次按钮变为“完成”
- [ ] “先用仅复制模式”或直接关窗后，再次启动不再弹引导
- [ ] 菜单栏：显示面板 / 贴回状态行 / 设置… / 清空历史（二次确认）/ 退出
- [ ] 通用：热键、登录时启动、失焦关闭延迟、选中停下后展开行数
- [ ] 历史：保留时长、最多保留条数、单条截断、收藏永久保留
- [ ] 隐私：隐私模式开启后不再记录；自动排除疑似密钥开启后复制 `sk-…` 不进历史
- [ ] 高级：默认编辑器、OCR 语言、在访达中显示数据目录、清空历史（二次确认并删除图片文件）、版本号

## 4. 性能

- [ ] `make measure PID=<pid>`：常驻内存 < 50MB，空闲 CPU ≈ 0
- [ ] 连续复制 1 小时无线性内存增长
- [ ] `make bench`：10 万条高选择性检索 < 10ms
- [ ] 快速键盘导航滚动跟手；图片缩略图异步加载，滚动不卡
