# jiantieban PRD

相关文档：[architecture](../architecture.md)（技术）、[STATUS](../STATUS.md)（实现状态）、[DESIGN](../DESIGN.md)（界面规则）、[ADR-0001](../adr/0001-jt-is-the-secret-source-of-truth.md)（密钥模型）。

## 1. 问题与定位

jiantieban 是 macOS 原生剪贴板管理器：内存低、CPU 空闲为零、毫秒级搜索，界面用系统 Liquid Glass，没有第三方依赖。

它还解决一个具体场景：开发者要把 API Key / Token 交给 Agent 用，但不想把明文贴进对话，也不想手写文件、给路径、用完再删。做法是把剪贴板里的一条记录标记为密钥，真值交给本地的 [jt](https://github.com/catoncat/jt) 保管，面板贴出的是 `jt://secret/<id>` 引用，Agent 通过 Skill 调 `jt resolve --exec` 在运行时取值，明文不进对话。App 是 jt 的原生界面，不是密码管理器。

## 2. 目标用户

- 开发者 / Agent 重度用户：需要把密钥交给 Claude Code、Cursor 等使用。
- 普通 macOS 用户：只用剪贴板历史、搜索、收藏；不装 jt 也完整可用。

## 3. 核心功能

### 3.1 剪贴板

- 采集文本和图片；图片 OCR 后可搜。
- 全文搜索，前缀 `:text` `:img` `:fav` `:secret`（缩写 `:t` `:i` `:f` `:s`）；搜索框为空时 ←/→ 切换筛选。
- 收藏、删除（⌘Z 撤销）、用编辑器或默认 App 打开、⌘1–9 贴回视口内第 n 行。
- 贴回：有辅助功能权限时一键贴回目标 App；没有时写入剪贴板，提示“已复制，请按 ⌘V 粘贴”。
- 保留策略：默认 24 小时、600 条；收藏默认永久；贴回过的记录永久保留（只复制不算）。
- 可选记录 Chrome / Helium 普通窗口的页面标题和 URL，展开时显示，⌥⌘O 回到原页面。
- 隐私模式（暂停记录）、自动排除疑似密钥。

### 3.2 密钥

- **标记**（⌘L 或右键）：真值交给 jt 新建一条记录，原剪贴板记录变成只存引用的“引用记录”；随即进入命名，预填 `命名空间/KEY` 建议；提示“已存为密钥 · ⌘Z 撤销”，只能撤销最近一次。
- **粘贴为密钥**（⌘↩）：标记并贴出引用，不打断粘贴，用默认名，不给撤销。
- **没有取消密钥**：要明文就贴明文或查看；不要了就在密钥视图删除。
- **密钥视图**（`:secret`）：列出 jt 里全部记录，按命名空间分组；只按名称搜索；可贴引用、贴明文、查看、改名（`jt mv`）、删除（再按一次确认后 `jt rm`，不可撤销）。
- **引用记录**：名称和遮罩以 jt 为准；jt 里已删时显示“密钥已删除”，只能删除这条记录（不动 jt）。
- **遮罩**：前 2 + `••••••` + 后 4。

粘贴语义：

| 动作 | 普通记录 | 引用记录 / 密钥视图里的记录 |
|---|---|---|
| ↩、⌘1–9 | 贴原文 | 贴引用 `jt://secret/<id>` |
| ⌘↩ | 标记为密钥并贴引用 | 贴引用 |
| ⌘⇧↩ | 贴原文 | 贴明文 |
| ⌘R | 展开全文 | 展开显示明文和引用 |

### 3.3 Agent 集成

- 密钥命令行统一走 jt：`jt ls`、`jt resolve <引用> --exec <命令>`（真值只进子进程环境变量 `JT_SECRET`，`--env NAME` 改名）、`jt mv`。
- `jiantieban` CLI 只保留剪贴板相关命令和 `mark-secret`；旧的 `secrets` / `annotate` / `resolve` / `unmark-secret` 只打印去向，退出码 2。
- Skill `skills/jiantieban-secret/SKILL.md`：见到 `jt://secret/` 时触发；只用 `--exec` 消费真值，不把真值写进对话或日志；只有用户给出或上下文明确指向时才命名，不自行编造。

## 4. 非功能要求

- 普通记录的采集、搜索、滚动不受密钥功能影响；普通面板路径不启动 jt。
- 零第三方依赖；App 不联网、不上传。
- 不弹 Keychain / Touch ID 授权。
- macOS 26+。

## 5. 决策

1. 密钥以 jt 为唯一来源，App 从不执行 `jt sync`，只在密钥视图提示有未同步的改动（ADR-0001）。
2. 在密钥视图删除 = `jt rm`，要再按一次确认；不用弹窗，因为面板失焦即关。在时间线删除引用记录不动 jt。
3. jt 主密钥由用户自己备份；丢失后 vault 无法解密，App 不管理主密钥。
4. 全部视图的搜索不混入 jt 记录：会破坏列表结构、容易引入 bug；密钥只在密钥视图里搜。
5. 贴明文（⌘⇧↩）不加二次确认，靠默认贴引用保证安全。
6. MCP 不是必需；Skill + jt CLI 是默认集成方式。

## 6. 不做

- iCloud / 跨设备同步、跨平台、插件系统、团队 / 企业权限。
- 完整密码管理器、普通历史整体加密、云账号。
- 富文本 / 文件复制。
